# Web1 - Aplicación Web con Node.js y MySQL

Este proyecto es una aplicación web desarrollada con **Node.js**, **Express**, **EJS** y **MySQL**. Permite gestionar clientes, productos y visualizar detalles de productos desde una base de datos.

## Características

- **Gestión de Clientes**: Agregar y visualizar clientes desde la base de datos.
- **Tienda**: Visualizar una lista de productos disponibles.
- **Detalles del Producto**: Ver información detallada de un producto, incluyendo imágenes, precio, descripción y stock.
- **Conexión a MySQL**: Configuración segura para conectar con una base de datos MySQL.

## Requisitos

- **Node.js**: v14 o superior
- **MySQL**: v5.7 o superior
- **NPM**: v6 o superior
